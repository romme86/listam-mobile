## Archive and upload

1. Open `ios/listam.xcworkspace` in Xcode.
2. Choose the `listam` scheme and **Any iOS Device (arm64)** (or a connected
   iPhone). Confirm Version **1.3.4**, Build **24**, and the existing automatic
   signing team.
3. Choose **Product > Archive**. The shared scheme uses Release for archives.
4. In Organizer, select the new archive, then **Distribute App > App Store
   Connect > Upload**. Complete the existing account/signing prompts.
5. Wait for processing in App Store Connect, then assign build 24 to the
   intended TestFlight testing group and add the test notes below.

The newest pre-existing local archive was 1.3.3 (23). App Store Connect's build
history was not queried. No upload or tester distribution is performed by this
preparation.

## Shared-backend rollout

This build embeds the deterministic membership/re-key and legacy-ticket causal
validation fixes committed in `listam-packages` at `01f4412`. Coordinate updates
to desktop/headless peers sharing the same bases: the changes affect which newly
applied operations are admitted. Git pushes alone do not update installed peers.

Existing divergent materialized views are not automatically repaired by these
fixes. Test existing shared bases and recovery flows before wider distribution.
The full rationale and limitations are in `listam-tools/reviews/2026-09-05-follow-up.md`.
