# Mobile release 1.3.5 — 13 September 2026

Android **22** is available to internal testers in Google Play. iOS **25** was
successfully uploaded to App Store Connect using the existing signing account;
TestFlight processing and distribution are checked separately from upload.
Public-store production promotion remains subject to the device acceptance
checks below, following the previous release's internal-testing workflow.

## Source and validation

- Mobile implementation: `c97d594a88ed54fe184df1e18af4b0886714a275`.
- Shared packages: `e2dbfc2`, backend **0.10.2**.
- Autobase **7.28.2**, Hyperswarm **4.17.1**, Hypercore **11.36.1**,
  Corestore **7.12.5**; HyperDHT **6.34.0**, udx-native **1.21.1** retained.
- Both Bare backend bundles rebuilt from the final shared source. The freshness
  gate verifies hashes of backend sources, lockfiles and resolved dependencies.
- Mobile CI passed, including **179 Node tests**, type checking, lint,
  dependency/bundle checks and grocery intelligence checks.
- Signed Android release build, signed iOS archive and IPA export all passed.
  Existing upload/signing identities were reused.
- Play validated version **22 (1.3.5)**, minimum API **29**, target **36**, all
  four ABIs, and attached native debug symbols. Its device-support comparison
  reports no removed devices. The sole warning was the absent deobfuscation
  mapping; R8/minification is disabled for this build.
- Apple upload completed successfully. Apple reported missing dSYMs for some
  vendor libraries; native crash symbolication for those libraries is limited.

## Before public production

This release did not repeat the physical Wi-Fi/offline/cellular switch matrix,
billing/restore tests, 16 KB Android runtime test, or existing-install upgrade
checks. Run those with store-installed builds, along with Notes, shared-list
joining, background/resume catch-up and offline cold restart. Do not substitute
the prior 1.3.4 emulator smoke for validation of this new native artifact.

The upstream optional latest-block experiment, push delivery, Autobee migration
and unreleased libudx patches remain disabled or deferred. Relay configuration
is present in the native bundles; only an actual encrypted relay probe proves
that a particular connection used a relay.

## Release notes

More reliable peer connections with two relay options. Improved offline sync
and recovery. Notes editing and planning improvements.
